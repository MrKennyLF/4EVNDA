# 🥽 Laboratorio VR: Fundamentos para Simuladores Industriales

Repositorio base para la clase de Programación en Realidad Virtual. Este proyecto contiene el entorno preparado y preconfigurado para desarrollar mecánicas de interacción orientadas a simuladores de entrenamiento técnico e industrial.

**Objetivo:** Desarrollar las competencias de programación lógica (Máquinas de Estado, Eventos de Interacción y Físicas) necesarias para el desarrollo de simuladores.

---

## 🛠️ Requisitos Técnicos

Para evitar problemas de compatibilidad durante la sesión, asegúrate de cumplir con los siguientes requisitos antes de abrir el proyecto:

*   **Motor Gráfico:** Unity `[6000.3.24f1]
*   **SDKs Preinstalados en el proyecto:** XR Interaction Toolkit (XRI), OpenXR Plugin.
